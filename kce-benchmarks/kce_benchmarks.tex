I benchmarked this branch on an AMD Turin CPU and an RTX Pro 6000 using the following commands:

\begin{tabular}{@{}l@{}}
\texttt{DEV=CPU ROUNDS=8 CASE=KCE\_LARGE OUT=<path to dump> gmake -s new\_run} \\
\texttt{DEV=CUDA:PTX ROUNDS=8 CASE=KCE\_LARGE RT=1 OUT=<path to runtime dump> gmake -s new\_run} \\
\end{tabular}

The upstream commit that I benchmarked against was \texttt{9174ccc48}. The runtime numbers parse \texttt{DEBUG=2} kernel times and sum them.

To reproduce everything, just initialize the \texttt{tinygrad-base} submodule, set up a venv at the project root, and run the above two commands with whichever backends you want.
